# AfriCoT-VLA prototype

Single-junction prototype of AfriCoT-VLA, a traffic signal control system for Sub-Saharan African cities. It couples a vision-language-action model with Chain-of-Thought reasoning to a latent world model through a compact subgoal, and it is evaluated in SUMO.
