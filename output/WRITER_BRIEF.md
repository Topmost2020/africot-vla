## Markdown source format (build script contract)
- `# ` = chapter heading (write the number in text, e.g. `# Chapter 1: Introduction` for dissertation chapters; for the paper `# Introduction`), `## ` = section (write numbers, `## 1.1 Background`), `### ` = subsection (`### 1.1.1 ...`). No deeper levels.
- Paragraphs separated by blank lines. Bold/italic with ** and *. Inline code with backticks only for file names or identifiers.
- Figure: a line `![[figure:FILE.png|Caption text without number]]`. Cite in prose naturally ("the figure below"), with the figure placed right after the paragraph that introduces it.
- Table: a line `Table: Caption text without number` immediately followed by a pipe table (header row, separator row, rows). - Equations: write plain text or Unicode math on its own paragraph; keep few.
- Appendix material (dissertation only) uses `# Appendix A: ...`.
- Do not write the title page, certification, dedication, acknowledgement, abstract (assembler does, unless your task says so), references list, or table of contents.
